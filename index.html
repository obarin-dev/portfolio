キャリアチェンジのきっかけ

今後の目標

保育士としての経験とIT知識を掛け合わせ、人が育つ仕組みや、現場の負担を減らす仕組みづくりに関わっていきたいと考えています。

仕事で大事にしていること

  • 現場の困りごとから始めること。個人開発中の shift-manager は、自分が勤務表作成で苦労した経験がそのまま出発点になっています。

  • 自分以外も使える状態にすること。登園管理のデジタル化では、担任だけでなく他の保育士や主任も園児の登園状況を把握できる体制まで整えました。

プロジェクト事例

shift-manager（勤務表作成アプリ）

GitHub

保育園で勤務表作成に苦労した自身の経験をもとに開発している、保育園向けのシフト管理アプリケーション。保育時間・勤務区分・職員・クラスの登録から勤務表の作成までを扱えます。

使用技術Next.js（App Router）/ React / TypeScript / PostgreSQL + Prisma / JWT認証（jose・bcrypt）/ Google Gemini AI / Vitest / GitHub Actions
役割個人開発（要件定義〜設計・実装・テスト・CI構築まで一人で担当）
規模TypeScript 約190ファイル / テスト25ファイル / Prismaモデル13種 / 257コミット
工夫した点AIによる勤務表生成は、APIキー未設定時にルールベース生成へフォールバックする設計にし、AIが使えない環境でも動作するようにしました。

ai-magic-kids

GitHub

娘が描いた絵をAIが読み取って骨格データを抽出し、それを子ども自身がブロック命令で動かす親子向けアプリ。「AIが勝手にアニメーションを作る」のではなく、「AIが抽出した座標をどう動かすか」を子どもが考える体験を大切にしています。試作段階のプロジェクトです。

使用技術Next.js / React / TypeScript / Python（線画抽出）/ Google Gemini 1.5 Flash（マルチモーダル）
役割・目的個人開発（コンセプト設計〜試作）
工夫した点低学年の子どもが直接AI APIを扱えない制約を踏まえ、「親がエンジンを設計し、子どもが操縦する」という役割分担で設計。座標という算数の概念を遊びながら学べる構成にしています。
