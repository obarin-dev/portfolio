これまでの取り組み

shift-manager（勤務表作成アプリ）

GitHub

保育園の勤務表作成に毎月苦労した自身の経験をもとに開発している、保育園向けのシフト管理アプリケーションです。保育時間・勤務区分・職員・クラスの登録から勤務表の作成・公開までを扱えます。保育現場の業務フローを、そのまま要件に落とし込んでいます。

現場との接点休園日は自動で「休」になる、担任以外も勤務状況を把握できる、印刷して掲示できる——実際の運用で必要になる挙動を優先して実装しています。
使用技術Next.js（App Router）/ TypeScript / PostgreSQL + Prisma / AWS（EC2）+ Docker Compose / GitHub Actions（CI/CD）/ Google Gemini AI
役割個人開発（要件定義〜設計・実装・テスト・本番環境構築まで一人で担当）
運用GitHub の Issue・Pull Request でタスクを管理し、継続的に機能追加・改善（PR約90件）。本番環境ではバックアップとコストアラートも設定しています。
工夫した点AIによる勤務表生成は、APIキー未設定時にルールベース生成へ切り替わる設計にし、AIが使えない環境でも動作するようにしました。

子ども向けプログラミング授業の企画・教材制作

未就学児〜小学生向けに、90分のプログラミング授業を企画しました。「順序」「繰り返し」など伝える内容をあえて絞り、ひらがな中心のスライドと、体を動かして学ぶ活動の進行台本を作成しています。

意識したこと相手の前提知識に合わせて、何を伝えないかを決めること。説明する相手が変われば、伝え方も変える必要があると考えています。
制作物授業で使うため、命令を組み合わせて遊びながらプログラミングの考え方を学べるパズルアプリ（meirei-puzzle）も個人開発しました。
サポート職との関わり操作に不慣れな方への説明資料づくりや、導入研修の設計に直接活かせる経験だと考えています。
